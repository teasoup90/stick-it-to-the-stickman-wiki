# Game Wiki Meta Template Visual Reference

This file documents reusable visual rules only. Do not add a game logo, official artwork, or competitor screenshots to this directory.

## Reusable design rules

- Layout: constrained reading shell with a responsive content column and navigation sidebar.
- Typography: Geist Sans for interface and editorial copy; Geist Mono for code and data labels.
- Surfaces: neutral background, restrained borders, and theme-color accents set through `--nav-theme`.
- Media: each new game must provide a verified Hero asset and relevant category/article fallbacks. Do not reuse a previous game's Hero as a general article image.
- Advertising: no configured provider means no rendered ad slot and no reserved empty space.

## Neutral assets

- `public/images/logo.png`: original neutral Wiki mark.
- `public/images/hero.webp`: neutral setup placeholder. Replace it before Preview.
- Favicon and PWA icon files: derived from the neutral Wiki mark. Replace them once a new original mark has been approved.
