Stick It to the Stickman アンロック要素は2つのグループに分かれます。メインルートでゲームが手渡してくるものと、特定の手順の連鎖を完了した後にだけ現れる隠しキャラクターです。このページの元になっている保存済みガイドは後者のグループを扱っており、意図的にネタバレなしなので、驚きを台無しにされることなくルートをたどれます。

現在最もよく文書化されている Stick It to the Stickman アンロック要素は秘密キャラです。そのうちの1体はフルフィルメントセンターのルートの先にいて、対応するコミュニティガイドは53件の評価と6,800人以上のユニーク訪問者を集めており、保存済みソースの中でもっとも広く使われているアンロック資料となっています。

このガイドの最終更新は2025年9月下旬で、手順はキャラクターが実装された後のゲームを反映しており、ルートはその後のアップデートを経ても現役のままです。

以下はすべて、その保存済みガイドとコミュニティのメモに基づいており、各手順にはどの程度自信を持ってよいかが明記されています。ガイド自身が手順を不具合ありと記している箇所では、このページも警告を隠さずに繰り返します。

## フルフィルメントセンターの秘密キャラ

フルフィルメントセンターの秘密キャラは、ガイドの名前の由来になったアンロック要素です。作者は当初これを「新しい秘密キャラ」と呼び、キャラクターが登場してしばらく経ってから改名しました。このことから、ポストローンチのアップデートで追加された、比較的新しい Stick It to the Stickman アンロック要素の1つだと分かります。

ルートは3段階です。カメラを入手し、すべてのクモの巣を撮影し、その後犯罪者を逮捕します。ガイドが強調するのは、この連鎖全体がネタバレなしのウォークスルーだということです。つまり、連鎖の最後に何が起きるかを明かさずに行き先だけを教え、最後の引き渡しを完了するまでキャラクターの正体を隠し続けます。

Stick It to the Stickman アンロック要素を探すプレイヤーは、カメラが特定の地区でしかドロップしないのかどうかをよく尋ねます。ガイドには書かれていないので、インベントリがそうではないと証明するまでは、どの地区も対象として扱いましょう。

| アンロックの段階 | ガイドの説明 |
| --- | --- |
| 準備 | まずカメラを入手する |
| 収集 | マップ上のクモの巣を撮影する |
| 逮捕 | 投げ縄で犯罪者を捕まえる |
| 報酬 | 新しいキャラクターがアンロックされる |

## 手順1：カメラの入手

最初の手順は理屈では簡単で、実践では時間がかかります。カメラを入手するまで、街を回ってプレゼントを開け続けるのです。ガイドは、プレゼントはランダムなアイテムを出すため、カメラは候補の1つにすぎず、時間がかかることがあると正直に述べています。

コミュニティの報告は当然のアドバイスを付け加えます。カメラを一気に周回して狙うのではなく、普段のランで通りかかるプレゼントをすべて開ける、というものです。ドロップはランダムなので、専念した周回は一晩を溶かしかねませんが、通常プレイ中の受け身の収集なら、待ち時間はどうせやる予定だったランに分散されます。

何ランもプレゼントを開けてもカメラが出ない場合、ガイドに裏技はありません。ランダムドロップであり、粘り強さこそが戦略のすべてです。

| カメラの事実 | 詳細 |
| --- | --- |
| 探す場所 | 街中のプレゼント |
| 開けるもの | 通りかかるプレゼントをすべて |
| ドロップの性質 | ランダムで、時間がかかることもある |
| 最善の戦略 | ランをまたいで受け身で集める |

## 手順2：クモの巣の撮影

カメラがインベントリに入ったら、マップ上のすべてのクモの巣へ行き、カメラでそれぞれを撮影します。ガイドは3つの場所を挙げています。フルフィルメントセンターの左上、ファイナンスタワーのはるか左、社員評価センターの右下です。

ガイドは、撮影がときどき不具合を起こすことがあると警告しています。写真が登録されない場合の一般的な対処法は、位置を変えてもう一度試すことです。検出は、写真を撮るときの棒人間の立ち位置にうるさいため、少し角度を変えるとたいてい解決します。

| クモの巣の場所 | マップ上の位置 |
| --- | --- |
| 1つ目のクモの巣 | フルフィルメントセンターの左上 |
| 2つ目のクモの巣 | ファイナンスタワーのはるか左 |
| 3つ目のクモの巣 | 社員評価センターの右下 |
| 撮影の不具合 | 起きることがある。位置を変えて再試行 |

## 手順3：犯罪者の逮捕

正しくできていれば、電話アイコンが表示されます。それは写真が登録されたことの確認であり、次の段階を発動させます。投げ縄が出現するので、拾い上げましょう。

するとゲームはマップ上に3人の犯罪者をマークします。投げ縄を使ってそれぞれを警察署のドアまで連れて行き、3人全員を引き渡せば、新しいキャラクターがアンロックされるはずです。これは連鎖全体の報酬段階であり、ガイドはキャラクターの正体を隠したままにして、お披露目が楽しいままになるようにしています。

投げ縄は電話アイコンが表示された後にだけ出現します。投げ縄が見当たらない場合は、まず写真を確認しましょう。

| 逮捕の段階 | やること |
| --- | --- |
| 確認 | 電話アイコンを待つ |
| 道具 | 投げ縄を拾う |
| 標的 | マークされた3人の犯罪者 |
| 引き渡し | 警察署のドアまで連れて行く |

## ここで扱わないアンロック要素

保存済みガイドが扱う秘密キャラのルートはちょうど1つなので、このページは Stick It to the Stickman アンロック要素の完全な一覧をでっち上げません。ゲームは技、ゾーン、ゲームモードといった進行コンテンツも解放しており、コミュニティはそれらをSteamハブの別ガイドにまとめています。

ダークナイトやウェブスリンガーのルートなど、コミュニティガイドで言及される他の秘密キャラについては、手順の形は同じです。トリガーアイテム、一連のマップ目標、引き渡しの手順です。ただし、それらのルートはそれぞれ独自の保存済みソースに属するため、このページが保証するのはフルフィルメントセンターの連鎖だけです。

| カバー範囲 | 保存済みソースでの状態 |
| --- | --- |
| フルフィルメントセンターのキャラ | 完全に文書化済み |
| 他の秘密キャラ | 別のガイドで文書化 |
| アンロック要素の完全一覧 | 保存済みソースには未掲載 |
| 報酬の正体 | 意図的にネタバレなし |

## FAQ

### 最初に狙うべき Stick It to the Stickman アンロック要素は？

フルフィルメントセンターの秘密キャラが、もっともよく文書化された出発点です。対応するガイドが新しく、評価が付いており、キャラクター改名後に更新されているからです。

### 秘密キャラのルート用のカメラはどうやって入手しますか？

カメラがドロップするまで、街中のプレゼントを開けます。ガイドは、ドロップがランダムなので時間がかかることがあると記しています。

### ガイドがキャラクターを改名したのはなぜですか？

キャラクターがもう新しくなくなった時点で、作者は「新しい秘密キャラ」から「フルフィルメントセンターの秘密キャラ」へ改名しました。これは比較的新しい追加要素の1つだったことの裏付けです。

### この Stick It to the Stickman アンロック要素の手順は信頼できますか？

はい、1つだけ注意があります。ガイドは撮影の手順が不具合を起こすことがあると警告しているので、電話アイコンが一向に表示されない場合は、他の原因を疑う前に、少し位置を変えて写真を撮り直してください。

### このキャラ以外にも秘密キャラはいますか？

保存済みガイドが扱うのはフルフィルメントセンターのキャラだけです。他の保存済みソースは、ダークナイトやウェブスリンガーといったキャラの別ルートを、それぞれ独自の手順の連鎖つきで文書化しています。

### アンロックはランをまたいで維持されますか？

ガイドの枠組みから答えは明らかです。これらの連鎖でアンロックしたキャラクターはアンロックされたままです。ルートはランごとのボーナスではなく、恒久的な進行コンテンツとして扱われているからです。
