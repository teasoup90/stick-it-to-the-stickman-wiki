## ムーブシステムの仕組み

- ムーブは段階 1 で入手し、2 回まで昇格できるため、1 つの系統が 3 つのバージョンを持つことになります。
- 興味深いのは最後の段階です。このページの観察によると、ムーブの最上位段階は単に数値を大きくするのではなく、そのツールの用途そのものを再定義する傾向があります。
- 攻撃ボタンは、その時点で選択されているムーブを使用します。
- 選択はリストを循環するため、コンボとは 1 つのボタンを連打することではなく、異なるムーブを連続して繰り出すことです。
- 飛び道具のムーブは弾薬によって制限されます。弾切れになると、補充するか昇格させるまでそのムーブは使用できません。
- ダメージはパンチ、キック、飛び道具のいずれかとして発生し、この 3 つに当てはまらないものはすべてユーティリティに分類されます。

## パンチ系統

| 系統（段階 1 → 2 → 3） | 最終段階の効果 |
|---|---|
| Uppercut → Shoryuken → Dragon Punch | 最上位段階で炎をまとった一撃と短い前方への踏み込みが加わる |
| Karate Chop → Karate Strike → 100 Palm Punch | 2 段ヒットの振りになり、強い押し出しを伴う |
| Slap → Slap Parade → Thunder Clap | 単体接触が広範囲の拍手になる |
| Ponder → Normal Punch → Serious Punch | 長いチャージがついに実際のダメージとして決まる |

このページはアッパーカット系をゲーム内で最も信頼できる打ち上げ技と評価しています。純粋な対空手段として始まり、最終段階で燃焼を追加しつつ、着地位置も変わるからです。

## キック系統

| 系統（段階 1 → 2 → 3） | 最終段階の効果 |
|---|---|
| Forward Kick → Bicycle Kick → Street Sweeper | 連撃が 2 発から 3 発に増える |
| Roundhouse Kick → Spin Kick → Helicopter Kick | 射程が単体の敵から扇状の範囲に広がる |
| Jump Kick → Fly Kick → Stampede Kick | 群衆をなぎ倒しながら進む移動キック |

キックは相手の体を吹き飛ばし、壁や窓はダメージになるため、このページはキックが相手をどこへ送るかは、付随する数値と同じくらい重要だと論じています。

## 飛び道具と遠距離系統

| 系統（段階 1 → 2 → 3） | 最終段階の効果 |
|---|---|
| Coffee Mug Toss → Delivery Parcel → Mail Bomb | 投げた物が爆発する |
| Gun → Machine Gun → Mini Gun | 弾薬の消費がはるかに速くなる |
| Knife Throw → Shuriken → Hadoken | 刃がエネルギーの衝撃になる |

遠距離攻撃を外しても通常はコンボが維持されるため、このページはダメージが物足りなくても 1 つは携帯すべき理由として挙げています。代償は弾薬です。

## ユーティリティ系統

| 系統（段階 1 → 2 → 3） | 最終段階の効果 |
|---|---|
| Point → You are Fired → Downsizing | 同じ指示が複数の同僚に一度に下る |
| Strangle → Force Choke → Levitate Objects | 近接ではなく遠距離で機能する |
| Dodge Roll → Teleport → Black Hole | 回避が敵を閉じ込めるものに変わる |
| Hammer → Ax → Chainsaw | 遅い叩きつけが連続的な削りになる |
| Bored → Normal Side Hop → Serious Side Hop | 位置調整だったものが回避になる |

同じページによると、Levitate Objects と Black Hole は他のどのムーブの組み合わせよりも多くの苦しいランを救っており、その総評は、ランの結末を決めるのはダメージ系の選択ではなくユーティリティ系の選択だというものです。

## パークは別画面

ムーブの選択とパークの選択は別々にドラフトされ、パークがムーブの枠を消費することはありません。このページで人気のパークは、最大 HP 増加、被ダメージ減少、キックによる回復、キル時の弾薬返還、経験値増加です。パークは互いに積み重なるため、序盤の地味な体力系の選択が、終盤に取った派手なムーブを上回ることがあります。

## プレイヤーページからのドラフト指南

- 最初の 2 回の昇格は 1 つのパンチまたはキック系統に使う。
- その直後に、弱くてもよいので遠距離ムーブを入れる。コンボを維持し続けることが枠を使う価値があるというのが、このページの理由です。
- フロアが混み合い始めたら、ユーティリティムーブを追加する。
- 4 本目を開く前に、1 つの系統を最上位段階まで完成させる。
- リロールは、3 つの候補がすべて段階 1 の重複になったドラフトのために取っておく。

これらはゲーム内のどこにも明記されていない、プレイヤーの推奨事項です。

## FAQ

### Stick It to the Stickman のムーブはすべて何ですか？

2026-10-18 時点で、公式の Steam ページは個々のムーブ名を挙げていないため、照合できる公式リストはありません。上の表は stick-stickman.wiki に記載されている系統を再現したものであり、プレイヤーの寄せ集めであって、完全なリストとして確認されたものではありません。

### ムーブには本当にそれぞれ 3 つの段階があるのですか？

stick-stickman.wiki のプレイヤーメモは、各系統に 3 つの段階があり、最後の段階がムーブを再定義すると述べています。そのページにはビルド番号の記録がないため、後のパッチで系統が変わっている可能性があります。

### パークのドラフトは同じ選択画面の一部ですか？

いいえ。同じプレイヤーメモでは、ムーブの選択とパークの選択は別画面にあり、パークはムーブ枠を消費しないとされています。

### 最初にどの系統を段階 3 まで押し上げるべきですか？

そのページのドラフト指南は 1 つの系統を早めに完成させることを勧めており、アッパーカット系を最も信頼できる打ち上げ技と評価しています。これは公式ルールではなく推奨として受け取ってください。
