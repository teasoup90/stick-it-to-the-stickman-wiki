Stick It to the Stickman のダークナイトは、ゲーム最新の隠しキャラクターであり、解放クエストは本格的な夜勤作戦です。段ボールのCEOを壊し、無線に応答し、マップ中で犯罪ボスを狩ります。その間、5つ星の指名手配レベルがすべての行動を高くつかせようとします。ゲームで最も雰囲気のある解放のひとつで、報酬は努力に見合うキャラクターです。

この Stick It to the Stickman ダークナイトガイドは、保存済みのコミュニティガイド（hamsternick 作）に従います。そのガイドは、このキャラクターと red-gicide 実績をひとつのルートで記録しています。2つのルートは手順を共有するため、red-gicide との重なりも説明します。コミュニティスレッドのメモは、ガイド自体が省いた詳細を補う箇所に明記しています。

手順の前に警告をひとつ。このクエストにはファイナンスタワーの夜勤アクセスが必要で、日中にいくら探索しても必要なものは出現しません。夜勤をステップゼロとして扱ってください。それ以降はすべてきれいな順序で進みます。

## 解放クエストの手順

ガイド自身の要約は短いものです。ダークナイトを解放するには、夜勤を解放した後、マップ中にある5体の段ボールCEOをすべて壊します。次に無線を拾い、マップ中に出現するCEO犯罪ボスをすべて倒し、それが済んだら夜勤メニューを開きます。速度より順序が重要で、無線を飛ばすのが最も多く報告されるミスです。

ガイドはダークナイトがゲーム最新の隠しキャラクターだと述べています。コミュニティのコメントは、クエストがマップの夜勤バージョンでしか機能しないと付け加えます。段ボールCEOが実際に現れるのはそこだからです。このクエストの魅力は、強盗のチェックリストのように読めることです。壊し、応答し、狩り、報告する。ネタバレを嫌うプレイヤーも手順は平然と引用します。楽しみは読むことではなく実行することにあり、無線の後に始まる5つ星の追跡こそ、誰もネタバレされたくない部分だからです。

| 手順 | ガイドの説明 |
| --- | --- |
| 1 | 夜勤を解放する |
| 2 | 5体の段ボールCEOをすべて壊す |
| 3 | 無線を拾う |
| 4 | CEO犯罪ボスを倒す |

## 5体の段ボールを見つける

ガイドは段ボールを座標のリストではなく宝探しとして扱いますが、コミュニティが探索の輪郭を埋めています。段ボールはマップ中に散らばり、病院や上の道路など目印の近くにいくつかあります。目標ではなく秘密として狩り、それぞれの目印をゆっくり走査して、壊せる段ボールを二度通り過ぎないようにしましょう。

コミュニティのコメントは発動順を強調します。5体すべてを壊すことが次のマーカーを出現させる条件であり、5体すべてが壊れるまで無線はあなたにとって存在しません。夜勤なしの Stick It to the Stickman ダークナイト探索は、スレッドで最も多い出だしの失敗です。

あるコメントは重要な補足を加えます。段ボールはファイナンスタワーのマップの夜勤バージョンにしか存在しないため、日中のランは行き止まりであり、ガイドはそれを既知の前提としています。

| 探索のコツ | コミュニティのメモ |
| --- | --- |
| 上の道路、左上 | 最初の段ボールのエリア |
| 小屋の右側 | もう1体の段ボールが近くに |
| 病院の近く | 両側に段ボールあり |
| 5体すべてを壊した後 | 新しいマーカーが出現 |

## CEO犯罪ボス戦

段ボールがなくなると、新しいマーカーが現れます。そこへ行き、トランシーバーを見つけて拾うと、CEOを倒すよう指示されます。各CEO犯罪ボスの体力は5なので、銃なら一撃で倒せます。1体倒すと即座に5つ星が付くため、3体の出現でマップ全体が一斉に敵対的になります。コミュニティのコメントは、5つ星区間こそクエストの本当の難所だと述べています。

ガイドの装備アドバイスはこの数字から導かれます。事前に銃を持ち込みましょう。一撃武器は各ボスを、5つ星の指名手配下での5発の殴り合いではなく、1回のきれいな撃破に変えるからです。銃なしの Stick It to the Stickman ダークナイト挑戦は可能ですが悲惨です。ボスがそれぞれ5発も耐える間に指名手配レベルが積み上がるからです。

| ボスの詳細 | 意味 |
| --- | --- |
| 各体力5 | 銃なら各ボスを一撃 |
| 撃破で5つ星 | 強い指名手配圧を覚悟 |
| 3体のボス | 狩りはマップ全域に及ぶ |
| 無線が先 | ボスは無線の後しか出現しない |

## 適切な装備を持ち込む

夜勤は脆いビルドの来る場所ではありません。コミュニティの報告は、ボス用の銃、指名手配の追跡用の強力な群衆コントロール、そして撃破の合間を生き延びる十分な体力アップグレードを勧めます。マップは狩りの間ずっと敵対的で、撤退がきれいに済むことはめったにないからです。

ガイド自身の締めの言葉は正直です。全員を倒せばキャラクターが手に入る。隠しの第二段階も、隠しタイマーもなく、正しい順序の一撃撃破が3回あるだけです。

狩りの途中で死んでも、クエストは同じラン内の段ボール進行をリセットしません。ただし壊した段ボールが別のランをまたいで残るかはコミュニティの報告でも意見が分かれるため、最も安全な計画はクエスト全体を1回の夜勤セッションで試みることです。

| 装備枠 | 夜勤の選択 |

| 遠距離 | 一撃撃破用の銃 |
| 群衆コントロール | ボス間の追跡用 |
| 機動力 | マップ全域の狩りのための速い移動 |
| 持久力 | 5つ星の圧力に耐える体力 |

## FAQ

### Stick It to the Stickman でダークナイトを解放するには？

夜勤を解放し、5体の段ボールCEOをすべて壊し、無線を拾い、CEO犯罪ボスを倒し、それから夜勤メニューを開きます。キャラクターはその最後の手順で解放され、これが Stick It to the Stickman のダークナイト手順のすべてです。

### ダークナイトに夜勤は必要ですか？

はい。コミュニティのコメントは、ファイナンスタワーの夜勤アクセスが段ボールCEOを出現させる唯一の方法だと明言しています。日中のランで段ボールが出現することはありません。

### どの武器を持ち込むべき？

銃です。各CEO犯罪ボスの体力は5なので、銃なら一撃で倒せます。1体倒すと即座に5つ星が付くため、きれいな一撃が重要です。ボス戦は短く済み、本当の敵は指名手配レベルなので、銃ビルドが許すなら予備の弾薬を持ちましょう。

### Stick It to the Stickman のダークナイトはバットマンと同じ？

ゲーム内ではバットマンではなくダークナイトと呼ばれます。保存済みガイドはゲーム内の名前を確認しており、コミュニティのコメントは今もその違いをネタにしています。それが楽しみの半分です。ガイドの作者はコメントで何度もこの説明をしてきました。
