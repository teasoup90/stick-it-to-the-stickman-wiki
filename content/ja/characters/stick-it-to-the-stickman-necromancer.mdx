## 解放ルート

ネクロマンサーの解放は従業員評価センターにあり、フルフィルメントセンター産の血液50個が必要です。コミュニティの返信は、ネクロマンサーをカウボーイと同じアップグレード経路に置いています。つまり解放画面は分岐構造です。片側にヴァンパイア、もう片側にカウボーイとネクロマンサー。スレッドの最初の返信は、そこへ至るアップグレードとともに、そのことを明快に述べています。

血液はフルフィルメントセンターの献血システムから得られるため、実際の周回作業はヴァンパイアと同じものです。スレッドのプレイヤーたちは、ネクロマンサーの50個を支払うために、あえてヴァンパイアのしきい値を超えて血液を貯めると述べています。

カウボーイの詳細が重要なのは、解放画面の配置を説明してくれるからです。2人は分岐を共有しており、ネクロマンサーはその先にいます。彼が見えないプレイヤーは、たいてい画面位置が1つ手前なのです。スレッドの返信は血液の出所も確認しています。ある投稿者の言葉を借りれば「配達のアレから出る血」、つまりヴァンパイアのために既に使っている献血ループです。

| 血液の出所 | フルフィルメントセンターの献血 |

## ナビゲーションバグ

スレッドの展開は返信で訪れます。血液55個を持つプレイヤーが、ゲームがネクロマンサーへの移動を許さず、セレクターがヴァンパイアからカウボーイへ飛んでネクロマンサーを完全に飛ばすと報告しました。他の人たちも同じ問題を抱えていると返信し、これは一人の環境ではなくパターンだと分かります。

少なくとも1人のプレイヤーに効いた対処法は、他のキャラクターを先に解放することです。あるプレイヤーは、ヴァンパイアなど他のキャラクターを解放するとナビゲーションの問題が直り、ゲームが上へ移動してネクロマンサーを選べるようになったと報告しています。コミュニティの返信はこれを公式修正ではなく回避策として扱っています。

パターンの一貫性は、セレクターのナビゲーション状態がどのキャラクターを解放済みかに依存することを示唆しており、それは回避策が示唆する内容そのものです。このバグに当たった Stick It to the Stickman のネクロマンサー周回は、さらに集める前に回避策で止まるべきです。血液を増やしてもセレクターの状態は変わらないからです。

| 症状 | 報告された回避策 |
| --- | --- |
| セレクターがネクロマンサーを飛ばす | 先にヴァンパイアと他キャラを解放 |
| 血液はあるのに選択不可 | 評価センターに入り直す |
| アップデート後も詰まる | 最近のスレッドでパッチノートを確認 |
| 解放は成功するが遅く感じる | 最終的には選べるようになるとの報告 |

## 血液周回の計画

血液50個はキャラクターロースターで最も高い単一資源コストなので、周回をプロジェクトのように計画しましょう。スレッドのプレイヤーたちは、フルフィルメントセンターの献血ループ（ヴァンパイアの20個を賄うのと同じループ）で50個に到達すると述べており、2人分の合計コストこそが本当の終盤目標です。献血ランはループを解放すればすぐに積み上がり、ヴァンパイアとネクロマンサーを合わせた血液コストは、どの Stick It to the Stickman ネクロマンサースレッドでも本当の終盤目標です。

血液はランをまたいで持ち越されるので、この周回に失敗状態はなく、あるのは時間だけです。コミュニティの助言は、こまめに献血し、ネクロマンサー解放までは血液を他のことに使わないこと。50個を超えて貯めた投稿者たちは、選択の瞬間こそが本当のボス戦だと表現します。血液は入場料にすぎません。

| 周回の判断 | コミュニティの助言 |
| --- | --- |
| 貯めるか使うか | 50個まで全部貯める |

## スレッドが残す未解決点

スレッドはナビゲーションバグが公式に修正されたかどうかを確認しておらず、返信は数か月にわたるため、バグはバージョン依存の可能性があります。つまり血液の総量より自分のビルドの方が重要です。正直なまとめは、すんなり解放できるプレイヤーもいれば、飛ばしに当たるプレイヤーもいて、回避策はその一部に効くということです。

血液50個を集める前に、現在のディスカッションスレッドで評価センターの画面が自分のビルドで正常に動くか確認しましょう。その確認を省いた Stick It to the Stickman のネクロマンサー計画は、操作できない画面に向かって周回する危険を負います。スレッドは生きた文書として扱ってください。上位の返信が回避策で、最新の返信が状況報告です。

| 周回前に | 理由 |
| --- | --- |
| 最近のスレッドを確認 | バグの状況はパッチごとに変わる |
| 血液カウンターの表示を確認 | 画面が進行状況を示す |
| 先にヴァンパイアを解放 | ナビゲーションが改善するとの報告 |
| 予備の目標を持つ | カウボーイが同じ経路にいる |

## バグを避ける解放順

回避策は順番を示唆しています。先にヴァンパイアと他のキャラクターを解放し、それから血液50個を持って評価センターへ戻る。この順番に従うプレイヤーはセレクター問題が少ないと報告しており、隣のキャラクターが解放済みになると画面が正常に振る舞うことを示唆します。開発者の投稿で原因が確認されたわけではありませんが。

| 順番 | 理由 |

| 3. 血液50個を貯める | ネクロマンサーの入場料 |
| 4. 評価センターへ戻る | 同じ経路で彼を選ぶ |

## FAQ

### Stick It to the Stickman でネクロマンサーを入手するには？

フルフィルメントセンター産の血液50個を持って従業員評価センターに到達し、解放画面で彼を選びます。カウボーイと同じアップグレード経路にいて、カウボーイが解放される画面で完全な解放に到達できます。

### ネクロマンサーを選択できないのはなぜ？

スレッドで知られるナビゲーションバグです。セレクターがヴァンパイアからカウボーイへ飛び、彼を飛ばします。ヴァンパイアなど他のキャラクターの解放で直ったプレイヤーが少なくとも1人おり、Stick It to the Stickman のネクロマンサースレッドの複数の返信が同じ行き詰まり状態を報告しています。

### ネクロマンサーには血液がいくつ必要？

50個です。ヴァンパイア解放が20個に使うのと同じ、フルフィルメントセンターの献血ループで貯めます。スレッドが記録するキャラクターコストの中で最も高く、献血ランがスレッドで名指しされた唯一の出所です。

### Stick It to the Stickman のネクロマンサー解放画面はどこ？

従業員評価センターの、カウボーイと同じ経路です。彼を選ばせてもらえない場合は、先に他のキャラクターを解放してから戻ってみてください。回避策の返信はスレッドで最も評価の高い助けであり、このページ末尾のリンクがやり取りの全文を開きます。
