## 汗を落とす敵

汗は汗だくの建設作業員が落とします。この敵タイプは保存済みの記録における汗の供給源のすべてであり、表現からすると作業員は見た目で区別できますが、スレッドは名前以上に見た目を説明していません。

これらの作業員の1体を倒すと、汗の水たまりを落とします。汗を得るにはそれに触れる必要があります。この「触れる」手順こそプレイヤーが見逃す部分です。水たまりはキルの後に地面に残り、その上を歩くことで初めてリソースが計上されます。

保存済みの表現は、作業員ではなく水たまり自体をリソースとして扱っています。キルが水たまりを生み、触れることが汗の残高を生むのです。だから素早いプレイヤーは部屋を一掃しても手ぶらで去ることがあります。

| 汗の事実 | 詳細 |
| --- | --- |
| 敵 | 汗だくの建設作業員 |
| ドロップの種類 | 地面の汗の水たまり |
| 回収 | 水たまりに触れる |
| 見逃す人 | 通り過ぎてしまうプレイヤー |

## 作業員の出現場所

スレッドは2つの場所を挙げています。主にフルフィルメントセンター、そして$15難易度のファイナンスタワーです。「主に」という言葉は重要で、フルフィルメントセンターを主力の農場、ファイナンスタワーを第二の農場にしているからです。

$15難易度の注記は実用的なコツです。汗が必要なのにフルフィルメントセンターでは足りないなら、同じ作業員タイプが出現する$15設定でファイナンスタワーを走りましょう。

どちらの場所にも出現率は付いていないので、このページはランあたりの汗の数を約束できません。約束できるのは、この2か所が保存済みスレッドの挙げる唯一の場所だということです。

他の建物での Stick It to the Stickman 汗の入手方法を尋ねるプレイヤーは、保存済みの記録を超えた質問をしています。正直な答えは、汗の供給源として文書化されている他の場所はない、というものです。

| --- | --- |
| フルフィルメントセンター | 主な出現場所 |
| ファイナンスタワー、$15難易度 | 第二の出現場所 |
| 他の場所 | 保存済みスレッドでは言及なし |
| 夜勤 | ゴーストであって汗ではない |

## 汗を効率的に集める方法

収集ループは簡単です。指定された場所に入り、汗だくの作業員を倒し、先へ進む前にすべての水たまりに触れます。スレッドは出現率を説明していないので、各フロアは保証された数ではなくサイコロの目として扱いましょう。

コミュニティの報告は役立つ習慣を1つ加えます。回収する前に部屋を完全に片付けることです。水たまりは作業員が倒れた場所に残るため、戦闘の途中で拾うと、まだ倒していない作業員のドロップを見逃す危険があります。

同じ習慣はファイナンスタワーのランにも当てはまります。$15難易度では作業員は他の脅威とフロアを共有するので、まず戦闘を終え、それからフロアを水たまりがないか掃きましょう。

| 収集手順 | 重要な理由 |
| --- | --- |
| 正しい場所を選ぶ | 作業員は名前のある2か所に出現する |
| 戦闘を終える | キルがドロップを発生させる |
| すべての水たまりに触れる | 回収は手動 |
| フロアを掃く | ドロップは作業員が倒れた場所に残る |

## 汗と血液の比較

汗と血液はどちらも進行アップグレードの条件ですが、方法は正反対です。汗は特定の敵からの戦闘ドロップであり、血液はフルフィルメントセンターのステーションで体力を寄付することで得られます。

つまり、あるランは汗に最適でも血液には役に立たないことがあり、その逆もあります。アップグレードが両方を必要とするなら、1つのルートで両方をまかなおうとせず、2つの別々のループを計画しましょう。

| リソース | 入手方法 |
| --- | --- |
| 汗 | 汗だくの作業員を倒し、水たまりに触れる |
| 血液 | センターで体力を寄付する |
| クリップ | ファイナンスタワーで箱を壊す |
| 帽子 | 新しいキャラクターか難易度でCEOを倒す |

## 帽子のボーナス事実

同じ返信は、誰も直接尋ねなかった質問に答えています。帽子の入手方法です。新しいキャラクターまたは新しい難易度でCEOを倒せば、帽子はあなたのものです。

この詳細はリソースの全体像を仕上げ、コミュニティがCEOを農場可能なボスとして扱う理由を説明します。新しいキャラクターや難易度での挑戦は、そのたびに再び報酬を払うからです。

| 帽子の事実 | 詳細 |
| --- | --- |
| 条件 | CEOを倒す |
| トリガー | 新しいキャラクターまたは新しい難易度 |
| 繰り返し可否 | 可、新しいランごとに |
| 用途 | 進行リソース |

集めている途中のプレイヤーへの最後の繰り返しです。作業員が供給源、水たまりが回収手段、名前のある2か所がこの方法の地図のすべてです。ランのどこにもこの3つがなければ、建物を間違えています。

## FAQ

### Stick It to the Stickman で汗はどうやって手に入れますか？

フルフィルメントセンターまたはファイナンスタワーの$15難易度で汗だくの建設作業員を倒し、彼らが落とす汗の水たまりに触れます。

### 汗だくの建設作業員はどこにいますか？

### 水たまりには触れる必要がありますか？

はい。スレッドは、汗を得るには落ちた水たまりに触れる必要があると述べています。回収は自動ではなく手動です。

### 汗だくの作業員はフルフィルメントセンターのすべてのランに出現しますか？

### Stick It to the Stickman 汗の入手方法はどの難易度でも同じですか？

### 部屋を離れると汗は消えますか？

### どのキャラクターでも汗を集められますか？

スレッドは作業員を特定のキャラクターに結び付けていないので、彼らを倒せるキャラクターならどれでも汗を集められるはずです。
