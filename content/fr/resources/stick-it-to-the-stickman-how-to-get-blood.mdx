## La réponse en un mot : don

La réponse courte vient d'un joueur demandant comment débloquer la pièce de sang, celle qu'on utilise pour débloquer le vampire. La réponse tient en deux étapes : achetez le don de sang dans le Centre logistique, puis asseyez-vous dans le fauteuil.

Cette formulation compte parce qu'elle donne l'ordre : le centre de don est une amélioration que vous achetez d'abord, et le fauteuil est la chose que vous utilisez ensuite. Les joueurs qui entrent dans le Centre logistique sans l'amélioration ne trouveront ni la pièce ni le fauteuil.

## Débloquer le centre de don de sang

Le fil plus complet ajoute le côté amélioration de l'histoire. Vous devez débloquer le centre de don de sang dans le Centre logistique, ce qui signifie que le bâtiment a une exigence d'achat ou d'amélioration avant que le moindre sang ne coule.

Le fil ne dit pas ce que coûte le centre de don, donc cette page n'inventera pas de prix. Ce qu'il dit, c'est que toutes les quelques salles du Centre logistique, vous aurez l'occasion de donner de la santé et de gagner du sang, ce qui est la vraie boucle de farm.

L'expression toutes les quelques salles est le détail de rythme important : les offres ne sont pas une fois par run, ni assez aléatoires pour planifier précisément autour, mais assez fréquentes pour qu'une run complète à travers le bâtiment produise plusieurs chances de donner.

## Comment fonctionne la boucle de don

La boucle, c'est de la santé contre du sang. Toutes les quelques salles, le jeu vous offre la chance de donner de la santé, et l'accepter convertit cette santé en sang. L'échange est toute la mécanique, donc la décision de farm est toujours la même : combien de santé pouvez-vous vous permettre d'abandonner ?

Les rapports communautaires la présentent comme un choix de rythme plutôt qu'un cadeau. Si votre build se soigne facilement, donnez agressivement. Si votre run peine, sautez le fauteuil et donnez à l'offre suivante, car les offres se répètent à mesure que vous traversez le bâtiment.

Un autre point pratique de la formulation : le don est une occasion, pas une exigence. Le jeu demande, et vous décidez, ce qui signifie que le farm de sang ne doit jamais tuer une run, sauf si vous laissez l'avidité le faire.

## Le sang face aux autres devises

Le sang voisine avec la sueur et les gouttelettes d'eau dans le système de ressources, mais il fonctionne différemment. La sueur tombe des ennemis, tandis que le sang vient d'une station de don, ce qui fait du sang la seule ressource que vous achetez avec votre propre barre de santé.

Cette différence compte quand on planifie une run : farmer la sueur est une routine de combat, tandis que farmer le sang est une décision de survie. Une run excellente pour une ressource peut être terrible pour l'autre, donc ne supposez pas que la même route fonctionne pour les deux.
