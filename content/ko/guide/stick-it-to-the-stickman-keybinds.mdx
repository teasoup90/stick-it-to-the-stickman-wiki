Stick It to the Stickman 키 설정 질문은 대개 두 곳에서 옵니다. 사다리에서 헤매는 신규 플레이어, 혹은 2인 플레이어에게 컨트롤러를 넘기려는 협동 호스트입니다. 답은 보기보다 단순합니다. 기본 배치는 작고, 플레이어가 겪는 입력 문제에는 알려진 커뮤니티 해결책이 있기 때문입니다. 게임을 다시 설치해야 하는 것은 없습니다.

이 Stick It to the Stickman 키 설정 참고서는 커뮤니티 위키의 조작 페이지를 바탕으로, 개발자의 공식 itch.io 페이지로 기본기를 교차 확인했습니다. 그 외, 특히 협동 수정법은 커뮤니티 경험으로 표시합니다.

조작 페이지는 이동을 A와 D, 사다리와 점프를 W, 몸 낮추기를 S, 공격을 스페이스 또는 Z, 슬로 모션을 X로 나열합니다. 다섯 키가 게임 전체를 커버하므로, 입력이 이상하게 느껴질 때 리매핑이 진짜 문제인 경우는 드뭅니다.

## 기본 키보드 배치

위키 조작 페이지에 따르면 S는 몸을 낮춰 사다리를 내려가고, W는 사다리를 오르며 점프하고, A와 D는 이동, 스페이스 또는 Z는 공격, X는 업그레이드로 해금한 뒤 슬로 모션을 발동합니다. 이것이 완전한 기본 배치이며 공식 itch.io 기재(화살표 키로 이동, 스페이스로 공격, 엔터로 입장, X로 슬로 모션)와도 일치합니다.

두 페이지의 작은 차이는 짚을 가치가 있습니다. 위키는 WASD를, itch.io 페이지는 화살표 키를 설명하므로 게임은 취향에 따라 두 이동 스타일을 모두 받아들이고 동시에 작동합니다. 키보드와 컨트롤러 혼합 세팅이 흔한 이유입니다. 두 페이지는 핵심에서 일치하므로 Stick It to the Stickman 키 설정 치트시트를 만드는 사람에게 안심이 됩니다.

위키 페이지는 일부 조작이 특정 업그레이드 후에만 의미를 가진다고도 암시합니다. 슬로 모션이 게이트 뒤에 있다는 정중한 표현입니다. 공식 페이지는 같은 네 가지 기본기에 엔터를 더해, 배치가 데모 시절부터 안정적임을 확인해 줍니다.

| 키 | 동작 |
| --- | --- |
| A / D 또는 화살표 키 | 좌우로 이동 |
| W 또는 위 화살표 | 점프와 사다리 오르기 |
| S 또는 아래 화살표 | 몸 낮추기, 사다리 내려가기 |
| 스페이스 또는 Z | 공격 |

저장된 전체 참고서는 [커뮤니티 위키 조작 페이지](https://stick-it-to-the-stick-man.fandom.com/wiki/Controls)에 있으며, 패치로 기본기가 바뀔 경우 재확인은 공식 itch.io 페이지가 적합합니다.

## 각 키의 실제 역할

이동은 이야기의 절반입니다. 사다리 키가 중요한 이유는 여러 방과 지름길이 등반에 달려 있기 때문이며, S를 익히지 않은 플레이어는 단순한 수직 구간에서 막힙니다. W 점프는 처음엔 어색하지만 전용 점프 키를 기대하지 않으면 자연스러워집니다. 스페이스 공격도 마찬가지입니다.

커뮤니티 보고는 실용적인 메모를 더합니다. 게임은 사다리에서 탭과 길게 누르기를 다르게 읽으므로, 탭하지 말고 방향을 계속 누르라는 것. S를 탭하는 플레이어는 사다리 끝을 지나쳐 미끄러지지만, 길게 누르면 매번 깔끔하게 내려갑니다.

스페이스나 Z로 공격할 수 있다는 것은 양손에 닿는 선택지가 있다는 뜻으로, 한 명은 컨트롤러, 한 명은 키보드를 쓰는 협동에서 중요합니다. 엔터는 메뉴, 문, 그리고 itch.io 페이지가 나열하는 상호작용 프롬프트를 위한 키입니다.

| 입력 | 쓰는 때 |
| --- | --- |
| 스페이스 / Z | 약하든 강하든 모든 공격 |
| W 또는 위 | 위층 이동과 탈출 |
| S 또는 아래 | 사다리를 안전하게 내려감 |
| 엔터 | 메뉴, 프롬프트, 방 입장 |

## 슬로 모션과 해금 게이트

조작 페이지는 슬로 모션이 업그레이드로 해금한 뒤에만 작동한다고 적었습니다. 초반에 X를 눌러도 아무 일이 없으면 키가 고장이라고 여기기 쉽지만, 게이트는 입력이 아니라 진행입니다.

스레드는 해금이 한 번 사면 영구적이라고 확인합니다. 해결책은 슬로 모션 업그레이드를 사고 곧바로 X를 시험하는 것. 해금 후에도 X가 안 먹는다면, 다음 섹션에서 진짜 원인인 입력 충돌을 다룹니다.

반복해서 나오는 Stick It to the Stickman 키 설정 질문은 슬로 모션이 컨트롤러에서 되는가입니다. 커뮤니티 보고는 그렇다고 답하며, 같은 해금에 매핑되고 차이는 패드의 어느 버튼이냐뿐입니다. 현재 패드 매핑은 입력 설정 화면에서 확인하세요.

| 상황 | 대개 의미하는 것 |
| --- | --- |
| 초반에 X가 안 먹힘 | 슬로 모션 미해금 |
| X가 되다가 멈춤 | 입력 충돌 또는 리매핑 확인 |
| 사다리 키가 둔함 | 탭하지 말고 S나 W를 길게 |
| 공격 키가 밀림 | 스페이스와 Z를 시험해 깔끔한 쪽 사용 |

## 리매핑과 협동 입력 설정

리매핑은 게임 옵션에 있고, 건드리는 가장 흔한 이유는 협동입니다. 구버전 빌드는 키보드만 플레이어 1로 인식했기 때문에 호스트는 2인에게 컨트롤러를 주려고 우회책을 썼습니다.

저장된 스레드의 해결책은 첫 플레이어가 참가한 뒤 컨트롤러를 뽑았다 다시 꽂아 게임이 두 번째 기기로 인식하게 만드는 것이었습니다. 커뮤니티 보고에 따르면 이후 업데이트가 플레이어별 정식 기기 할당을 추가했으니, 먼저 입력 설정을 확인하고 재연결 트릭은 구버전 전용으로 쓰세요.

솔로 플레이어에게 리매핑 효과는 작지만, 모든 Stick It to the Stickman 키 설정 스레드에서 눈에 띄는 커뮤니티 팁이 하나 있습니다. Z로 공격한다면 W를 점프로 둬도 잘 작동하고, 엔터를 커스텀 바인딩에서 비워 두면 메뉴 오류를 피할 수 있습니다. 보고되는 리매핑 문제 대부분은 한 키에 두 동작을 묶은 데서 비롯됩니다.

| 협동 문제 | 커뮤니티 해결책 |
| --- | --- |
| 컨트롤러가 플레이어 1로 읽힘 | 설정에서 기기 재할당 |
| 두 번째 컨트롤러가 안 보임 | 참가 후 뽑았다 다시 꽂기 |
| 키보드 두 대가 멀리 있음 | Steam 리모트 플레이 또는 Parsec 사용 |
| 낡은 컨트롤러가 말썽 | 새 패드로 교체. 낡은 건 불안정 보고 있음 |

## 런 전에 입력 테스트하기

진지한 런 전 2분짜리 입력 점검이 많은 혼란을 막습니다. 커뮤니티 플레이어는 1층에서 사다리 키, 공격 키, X를 시험하고 이상하면 리셋합니다. 검증된 Stick It to the Stickman 키 설정은 연습해 본 적 없는 화려한 커스텀 배치보다 낫습니다.

| 점검 | 기대 결과 |
| --- | --- |
| 사다리 내려가기 | S 길게 눌러 부드럽게 하강 |
| 점프 | W로 위층 이동 |
| 공격 | 스페이스와 Z 모두 휘두름 |
| 슬로 모션 | 업그레이드 구매 시 X 작동 |

## FAQ

### Stick It to the Stickman 키보드 설정은?

A와 D로 이동, W로 사다리와 점프, S로 몸 낮추기, 스페이스 또는 Z로 공격, 엔터로 상호작용, X는 업그레이드 해금 후 슬로 모션을 발동합니다.

### 슬로 모션이 안 되는 이유는?

조작 페이지는 슬로 모션이 업그레이드 해금 후에만 작동한다고 적었습니다. 키가 고장이라고 단정하기 전에 먼저 업그레이드를 사고 X를 다시 시험하세요. 그래도 실패하면 리매핑 충돌을 확인합니다.

### 2인 플레이어에게 컨트롤러를 주려면?

현재 빌드에서는 설정의 기기 할당을 쓰고, 구버전에서는 커뮤니티 재연결 트릭(키보드로 먼저 참가한 뒤 컨트롤러를 뽑았다 꽂기)을 씁니다. 트릭은 주로 구버전용입니다.

### 멀리 떨어진 두 사람이 키보드로 플레이할 수 있나요?

네. 저장된 스레드는 Steam 리모트 플레이 또는 Parsec을 추천하며, 호스트가 Shift+Tab 오버레이 또는 Parsec 클라이언트로 친구를 초대합니다. 둘 다 안정적인 연결이 필요하고, 호스트가 먼저 오버레이를 테스트해야 합니다.
