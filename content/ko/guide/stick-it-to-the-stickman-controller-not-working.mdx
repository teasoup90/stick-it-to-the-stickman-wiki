포럼에 'Stick It to the Stickman 컨트롤러 작동 불가' 글이 올라올 때, 진짜 문제가 게임인 경우는 드뭅니다. 보고 대부분은 세 가지 원인으로 모입니다. 컨트롤러가 엉뚱한 플레이어로 인식됨, 패드 자체가 낡고 불안정함, 혹은 알맞은 도구 없이 먼 곳의 친구와 함께하려 함. 아래 해결법은 세 경우를 모두 다룹니다.

이 'Stick It to the Stickman 컨트롤러 작동 불가' 가이드는 커뮤니티 스레드가 실제로 쓰는 해결책을 시도할 순서대로 모았습니다. 저장된 Steam 토론과 그 답글을 바탕으로 했고, 각 우회책은 커뮤니티 경험으로 표시했으며, 스레드에서 아무도 검증하지 못한 조언은 뺐습니다.

좋은 소식이 있습니다. 저장된 스레드의 개발자 답글은 커뮤니티의 해결책이 확인되고 높이 평가받는다고 인정했고, 입력 시스템에는 이후 정식 기기 할당이 추가되었습니다. 컨트롤러 문제 대부분은 이제 설정 화면에서 풀리며, 난해한 재연결 의식의 시대는 거의 끝났습니다.

## 당연한 확인부터 시작하라

영리한 방법에 앞서 기본부터 제외하세요. 커뮤니티 스레드는 언제나 같은 첫 단계를 나열합니다. 패드를 다시 연결하고, 입력 기기 선택을 확인하고, 다른 게임에서 패드를 시험해 작동 여부를 확정하는 것.

컨트롤러가 다른 곳에서는 되는데 여기서만 안 된다면 문제는 하드웨어가 아니라 할당입니다. 어디서든 실패한다면 패드 문제이므로 아래 하드웨어 섹션으로 건너뛰세요. 어느 쪽이든 답은 5분 안에 나오고, 이 페이지가 체크리스트입니다. 단계를 건너뛰지 말고 위에서 아래로 진행하세요.

'Stick It to the Stickman 컨트롤러 작동 불가' 체크리스트가 시간을 아끼는 이유는 해결책이 가능성 순으로 정렬돼 있기 때문입니다. 연결, 할당, 하드웨어. 커뮤니티 보고에 따르면 대부분의 사례는 2단계에서 끝납니다.

| 확인 항목 | 제외되는 것 |
| --- | --- |
| 컨트롤러 재연결 | 느슨한 연결이나 절전 상태 |
| 다른 게임에서 시험 | 패드 고장인지 게임 문제인지 |

| 게임 재시작 | 업데이트 후 낡은 입력 상태 |

## 2인 플레이어 우회책

가이드 스레드의 우회책은 컨트롤러를 플레이어 2로 만드는 것이었습니다. 게임이 원래 키보드를 플레이어 1로 읽었기 때문입니다. 호스트는 먼저 키보드로 세션에 참가한 뒤 컨트롤러를 연결해, 게임이 그것을 두 번째 기기로 잡게 했습니다.

한 답글이 실용적인 절차를 더합니다. 키보드로 참가하고, 연결된 컨트롤러를 잠시 뽑았다가, 탭으로 이동한 뒤 다시 꽂는 것. 커뮤니티 보고는 이 절차가 할당 업데이트 이전 빌드에서 작동하고, 이미 있는 빌드에서는 조용히 실패한다고 설명합니다. 그래서 무엇을 뽑기 전에 빌드 종류가 중요한 것입니다.

| 설정 단계 | 중요한 이유 |
| --- | --- |
| 먼저 키보드로 참가 | 키보드가 플레이어 1을 차지 |
| 다음에 컨트롤러 연결 | 게임이 플레이어 2로 할당 |
| 무시되면 재연결 | 재감지를 강제 |
| 두 입력 모두 응답하는지 확인 | 할당이 자리 잡았는지 확인 |

## 현행 빌드의 입력 할당

스레드 작성자의 후기 답글은 게임이 이제 각 플레이어에게 입력 기기를 할당할 수 있게 되어 옛 우회책이 불필요해졌다고 적었습니다. 작성자는 가이드가 베타용으로 쓰였으며, 현행 빌드는 설정 화면으로 이를 제대로 처리한다고 말합니다.

빌드에 입력 할당 옵션이 보이면 그것을 쓰고 재연결 트릭은 완전히 건너뛰세요. 트릭은 구버전에서는 여전히 유용하지만, 현행 빌드에서는 한때 해결했던 바로 그 충돌을 만들 수 있으니, 두 방법은 대안으로 취급하고 절대 합친 의식으로 쓰지 마세요.

설정 화면에 패드가 보이는데 게임이 무시한다면, 커뮤니티 해결책은 기기를 제거하고, 게임을 재시작하고, 깨끗하게 다시 추가하는 것입니다. 세션 중간에 다시 추가하는 것이 할당 혼란을 가장 많이 일으키는 부분입니다.

| 빌드 종류 | 할 일 |
| --- | --- |
| 현행 빌드 | 설정에서 각 기기를 할당 |
| 구 베타 빌드 | 키보드 선행 + 재연결 트릭 사용 |
| 어떤 빌드든 솔로 | 내 패드가 기기 1인지 확인 |
| 어떤 빌드든 협동 | 플레이어마다 고유 기기가 있는지 확인 |

## 불량 패드와 하드웨어 해결법

저장된 스레드의 한 댓글 작성자는 직설적이었습니다. 낡은 컨트롤러는 좀 문제가 있다. 커뮤니티 권장은 새 패드로의 교체이며, Xbox 스타일의 로지텍 컨트롤러가 게임과 잘 맞는 저렴한 선택으로 언급됩니다.

무엇을 사기 전에 컨트롤러 펌웨어를 업데이트하고 다른 USB 포트나 케이블을 시험하세요. 커뮤니티 보고에 따르면 이 게임의 '컨트롤러 사망' 사례 중 의외로 많은 수가 사실은 케이블 단선이고, 유선 연결은 협동 중 블루투스 끊김도 없애 줍니다. 'Stick It to the Stickman 컨트롤러 작동 불가' 보고에 스틱 쏠림이 포함된다면 그것은 게임이 아니라 하드웨어입니다.

| 하드웨어 문제 | 커뮤니티 해결책 |
| --- | --- |
| 낡거나 닳은 패드 | 교체. 낡은 패드는 불안정 보고 있음 |
| 느슨한 케이블·포트 | 먼저 다른 포트와 케이블 시험 |
| 펌웨어 문제 | 패드 소프트웨어로 업데이트 |
| 블루투스 끊김 | 협동 중 유선으로 전환 |

## 먼 친구: 리모트 플레이와 Parsec

친구가 멀리 있을 때 스레드의 답은 두 도구 중 하나입니다. Parsec 또는 Shift+Tab 오버레이로 쓰는 Steam 리모트 플레이. 둘 다 호스트의 게임을 친구에게 스트리밍해, 게임 입장에서는 온라인 플레이가 로컬 협동이 됩니다.

커뮤니티 보고는 간편함에서는 오버레이를, 약한 인터넷에서의 연결 품질에서는 Parsec을 선호합니다. 어느 쪽이든 컨트롤러가 작동해야 하는 쪽은 호스트뿐이며, 게스트는 스트림을 통해 입력을 보내므로 호스트의 'Stick It to the Stickman 컨트롤러 작동 불가' 보고가 게스트의 것보다 중요합니다. 전체 대화는 [저장된 토론 스레드](https://steamcommunity.com/app/2085540/discussions/0/4410795530130381483/)에서 읽을 수 있습니다.

리모트 세션을 위한 마지막 커뮤니티 팁: 가능하면 두 플레이어의 입력 스타일을 맞추세요. 키보드와 컨트롤러가 섞인 스트림은 때때로 게임의 할당 로직을 헷갈리게 하기 때문입니다. 세션 중에 이상 현상이 생기면 게임 전체를 재시작하기보다 게스트가 오버레이로 재접속하게 하세요.

| 리모트 옵션 | 적합한 상황 |
| --- | --- |
| Steam 리모트 플레이 | 오버레이를 통한 빠른 설정 |
| Parsec | 약한 인터넷에서의 안정성 |
| 호스트 유선 설정 | 스트림 끊김 감소 |
| 음성 채팅 병행 | 누가 언제 리셋할지 조율 |

## FAQ

### Stick It to the Stickman에서 컨트롤러가 안 되는 이유는?

가장 흔한 원인은 기기 할당입니다. 패드가 엉뚱한 플레이어로 읽히는 것. 현행 빌드에서는 입력 설정을 확인하고, 구버전에서는 키보드 선행 트릭을 쓰며, 하드웨어를 탓하기 전에 다른 게임에서 패드를 시험하세요. 보고 대부분은 이 단계에서 해결됩니다.

### 컨트롤러를 플레이어 2로 만들려면?

먼저 키보드로 세션에 참가한 뒤 컨트롤러를 연결해 게임이 플레이어 2로 할당하게 합니다. 현행 빌드는 설정에서 기기를 직접 할당할 수 있고, 재연결 트릭은 주로 구 베타 빌드용입니다. 한 가지 더: 베타 시절의 'Stick It to the Stickman 컨트롤러 작동 불가' 스레드는 현행 빌드가 설정 옵션으로 대체한 트릭을 설명할 수 있으니 최근 스레드를 우선하세요.

### 'Stick It to the Stickman 컨트롤러 작동 불가'는 패드가 죽었다는 뜻인가요?

대개는 아닙니다. 먼저 다른 게임에서 패드를 시험하세요. 거기서 된다면 문제는 할당이고 설정 화면 해결책이 통합니다. 낡은 패드는 불안정하다고 보고되므로, 그 확인들이 실패한 뒤에만 하드웨어를 교체하고, 그 전에 다른 케이블을 시험하세요.

### 먼 곳의 친구와 함께할 수 있나요?

네. 커뮤니티는 Steam 리모트 플레이나 Parsec을 추천합니다. 둘 다 호스트의 게임을 스트리밍해 먼 친구가 로컬인 것처럼 플레이하게 합니다. 호스트 입력이 작동하는 한 게스트 스트림은 대개 괜찮아서, 리모트 세션이 로컬보다 문제 해결이 단순합니다.
