## The Default Keyboard Layout

The wiki controls page says S lowers your body to climb down ladders, W climbs up ladders and jumps, A and D move, Space or Z attacks, and X activates slow motion after you unlock it from upgrades. That is the complete default layout, and it matches the official itch.io listing: arrow keys to move, Space to attack, Enter to enter, and X for slow-mo.

The small differences between the two pages are worth noting. The wiki describes WASD, while the itch.io page describes arrow keys, so the game accepts both styles of movement input depending on what the player prefers, and both work at the same time, which is why mixed keyboard and controller setups are common. The two pages agree on the essentials, which is reassuring for anyone building a Stick It to the Stickman keybinds cheat sheet.

The wiki page also implies that some controls only make sense after certain upgrades, which is a polite way of saying slow motion is gated. The official page lists the same four basics plus Enter, confirming the layout has been stable since the demo era.

| Key | Action |
| --- | --- |
| A / D or arrow keys | Move left and right |
| W or up arrow | Jump and climb up ladders |
| S or down arrow | Lower body, climb down ladders |
| Space or Z | Attack |

## What Each Key Actually Does

Movement is only half the story. The ladder keys matter because several rooms and shortcuts depend on climbing, and players who never learn S report getting stuck on simple vertical sections. Jumping with W feels odd at first but becomes natural once you stop expecting a dedicated jump key, and the same goes for attacking with Space.

Community reports add one practical note: the game reads quick taps and holds differently for ladders, so hold the direction rather than tapping it. Players who tap S report sliding past the ladder top, while holding it descends cleanly every time.

Attack on Space or Z means both hands have a reachable option, which matters in co-op when one player is on a controller and the other on keyboard. Enter is the interaction key used for menus, doors, and the interaction prompts the itch.io page lists it for.

| Input | When you use it |
| --- | --- |
| Space / Z | Every attack, light or heavy |
| W or up | Reaching higher floors and escapes |
| S or down | Going down ladders safely |
| Enter | Menus, prompts, and entering rooms |

## Slow Motion and the Upgrade Gate

The controls page notes that slow motion only works once you have unlocked it from upgrades. Players who press X early and get nothing often assume the keybind is broken, but the gate is progression, not input.

Community threads confirm the unlock is permanent once bought, so the fix is to spend on the slow-mo upgrade and test X immediately afterward. If X still does nothing after the unlock, the next section covers the input conflicts that actually cause it.

A Stick It to the Stickman keybinds question that keeps reappearing is whether slow motion works on controllers. Community reports say yes, it maps to the same unlock, and the only difference is which button your pad uses. Check the input settings screen to see the current pad mapping.

| Situation | What it usually means |
| --- | --- |
| X does nothing early | Slow motion not unlocked yet |
| X works, then stops | Check for input conflicts or remapping |
| Ladder keys feel unresponsive | Hold S or W, do not tap them |
| Attack key feels delayed | Test Space versus Z, one may be cleaner |

## Remapping and Co-op Input Setup

Remapping lives in the game's options, and the community's most common reason for touching it is co-op. Older builds only recognized keyboards as player one, so hosts used workarounds to give controllers to player two.

The saved thread's fix was to disconnect and reconnect the controller after the first player joined, which forced the game to pick it up as the second device. Community reports say a later update added proper input device assignment for each player, so check the input settings first and only use the reconnect trick on older builds.

For solo players, remapping rarely changes much, but one community tip stands out in every Stick It to the Stickman keybinds thread: if you attack with Z, keeping W on jump still works fine, and leaving Enter free of custom binds avoids menu weirdness. Most reported remap problems come from binding two actions to the same key.

| Co-op problem | Community fix |
| --- | --- |
| Controller reads as player one | Reassign devices in input settings |
| Second controller invisible | Disconnect and reconnect it after joining |
| Two keyboards, far apart | Use Steam Remote Play or Parsec |
| Old controller misbehaves | Swap to a newer pad; old ones are reported flaky |

## Testing Your Inputs Before a Run

A two-minute input check before a serious run saves a lot of confusion. Community players test the ladder keys, the attack key, and X on the first floor, then reset if anything feels off. A Stick It to the Stickman keybinds setup you verified beats a fancy custom layout you have never practiced.

| Check | Expected |
| --- | --- |
| Ladder down | Hold S, descend smoothly |
| Jump | W sends you up a floor |
| Attack | Space and Z both swing |
| Slow motion | X works if the upgrade is bought |

## FAQ

### What are the Stick It to the Stickman keybinds on keyboard?

A and D move, W climbs and jumps, S lowers your body, Space or Z attacks, Enter interacts, and X activates slow motion after you unlock it from upgrades.

### Why does slow motion not work?

The controls page notes that slow motion only works once you have unlocked it from upgrades, so buy the upgrade first and test X again before assuming the key is broken. If it still fails after that, check remapping conflicts.

### How do I give a controller to player two?

Use the input device assignment in settings on current builds, or the community's reconnect trick on older ones: join with keyboard first, then disconnect and reconnect the controller. The trick matters mainly on older builds.

### Can two players play on keyboards over distance?

Yes. The saved thread recommends Steam Remote Play or Parsec, with the host inviting the friend through the Shift and Tab overlay or the Parsec client. Both need a stable connection, and hosts should test the overlay first.
