## The Controls in the Demo

The demo page lists the keyboard controls plainly: arrow keys to move, space to attack, enter to enter, and X to use slow-mo. That four-line control scheme is the entire control documentation in the saved demo page.

It matches the game's design: a physics brawler that keeps the input layer small so the chaos comes from the simulation, not the button count.

The slow-mo button deserves a highlight, because it is the one control that changes how the physics reads, and the demo page lists it right alongside the basics.
